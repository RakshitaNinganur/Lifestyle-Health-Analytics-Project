\# 🏥 Lifestyle Health Analytics Dashboard



An end-to-end \*\*Data Analytics Project\*\* that analyzes lifestyle and health data to identify trends in BMI, sleep, stress, disease risk, and overall health score. This project demonstrates the complete data analytics workflow using \*\*Excel, SQL, Python, and Power BI\*\*.



\---



\# 📌 Project Overview



The objective of this project is to analyze lifestyle and health-related data of \*\*5,000 participants\*\* and provide meaningful insights through data cleaning, SQL analysis, Python exploratory data analysis (EDA), and an interactive Power BI dashboard.



This project follows a complete data analytics pipeline:



\- Data Cleaning using Excel

\- Data Analysis using SQL

\- Exploratory Data Analysis (EDA) using Python

\- Interactive Dashboard using Power BI



\---



\# 🎯 Problem Statement



Health and lifestyle factors such as BMI, sleep duration, stress level, water intake, and occupation significantly impact an individual's overall health.



The goal of this project is to analyze these factors and answer business questions such as:



\- What is the average BMI of participants?

\- Which occupations have the highest stress levels?

\- Which cities have the highest average health scores?

\- How is disease risk distributed?

\- How does BMI affect health score?
